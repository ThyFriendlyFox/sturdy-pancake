# Use cases

Each case has the same shape.
**Ask** is what the user tells the AI. **Adjust** is what the user changes by hand in the component the AI shows.

## Quick social clip

**Ask.** The user adds 3 clips and types "make a 15 second story". The AI trims the clips, sets 9:16 and adds fade transitions.
**Adjust.** The Cuts & trims component opens. The user moves the end of clip 2 by 1 second.

## Title and captions

**Ask.** The user types "add a title that says Summer Trip". The AI adds a title with a pop animation.
**Adjust.** The Text & captions component opens. The user changes the color and the size.

## Fix the voice

**Ask.** The user types "my voice sounds too high". The AI lowers the voice pitch by 2 semitones.
**Adjust.** The Voice pitch component opens. The user drags the pitch slider while the video plays.

## Voiceover

**Ask.** The user types "I want to talk over the second clip". The AI moves the playhead to clip 2 and shows the Voice track.
**Adjust.** The user records a voiceover. The music gets lower under the voice.

## Music bed

**Ask.** The user adds a song and types "start the song at the chorus and fade it out". The AI sets the song start and the fade.
**Adjust.** The Music component opens. The user moves the song start by ear.

## Look and color

**Ask.** The user types "make it look warmer and more vintage". The AI applies the vintage look to all clips.
**Adjust.** The Color & filters component opens. The user lowers the warmth on 1 clip.

## Hype moment

**Ask.** The user types "add confetti and a flash when I jump". The AI uses view_frame to find the moment and adds the effects.
**Adjust.** The Motion graphics component opens. The user moves the effect start by 0.2 seconds.

## Make the pet glow

**Ask.** The user taps the dog. It lifts out with a glowing edge, a paw menu opens around it, and the app listens. The user says "make him glow and leave a light trail".
**Adjust.** The Subject card docks beside the dog. The user picks a color and lowers the strength.

## Copy an edit

**Ask.** The user adds an example reel on the talk screen and says "copy this". The AI lists the moves it found.
**Adjust.** The user switches off 1 move and taps Apply. Each move becomes a track they can open later.

## Edit by hand

**Ask.** The user swipes right to Tracks without asking the AI, and taps the Video track.
**Adjust.** The user splits, trims and reorders clips in place. The edits are logged as user edits, so the AI learns from them.
